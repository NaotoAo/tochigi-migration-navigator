# とちぎ移住サポートナビ 2026 (β版)

**🌐 本番公開URL:** [https://tochigi-migration-navigator.vercel.app/](https://tochigi-migration-navigator.vercel.app/)

栃木県内全25市町の移住支援金・住まい・子育て・新幹線通勤制度を完全網羅した、サーバーレス静的Webアプリケーションです。

## 特徴
- **完全サーバーレス（0円・常時高速稼働）**: Pythonなどのバックエンド不要。Vercel, Cloudflare Pages, GitHub Pages等の静的ホスティングにデプロイするだけで、世界最速のCDNから爆速配信されます。
- **4問のおすすめ市町診断**: あなたの希望（都心通勤、温泉・自然、里山農業、子育て、歴史文化）から最適な市町グループを瞬時に判定。
- **移住支援金シミュレーター**: 世帯区分と子どもの人数を選ぶだけで、受給可能額の目安（最大100万〜300万円超）を一瞬で計算。
- **全25市町リアルタイム検索**: エリア別・特徴タグ別・フリーワード検索に対応。
- **公式LINE相談連携**: 移住コーディネーターへの無料相談導線を完備。

## デプロイ方法
1. GitHubにリポジトリを作成し、本フォルダ内の全ファイルをプッシュ。
2. Vercelで該当リポジトリをインポートし、「Deploy」をクリックするだけ（設定変更不要）。
